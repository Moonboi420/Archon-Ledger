Welcome to Archon Ledger.

The purpose of this tool is to make rebalancing your portfolio simple.
Its basically just a convenient spreadsheet, but it checks the price for you.
It tells you which coins to buy or sell to meet your targets.

To run it please follow the steps:
1- Clone the repo
2- npm install
3- node server.js
4- Go to localhost:3000

If you don't know how to do this ask deepseek because its easy, but you will need to install node.
